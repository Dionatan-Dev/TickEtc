# TickEtc: Evolução ao Portfólio de Engenharia

Este projeto consiste na evolução, refatoração e modernização de um sistema originalmente desenvolvido como objeto de estudo para um **Trabalho de Conclusão de Curso (TCC) em Engenharia de Software**. 

O objetivo principal desta nova etapa é transformar a base acadêmica existente em um portfólio de alto nível, aplicando **práticas avançadas de desenvolvimento**, ferramentas de mercado e padrões arquiteturais consolidados.

---

## Objetivos de Evolução

* **Documentação:** Versionamento de requisitos e diagramas para documentar a evolução do pensamento arquitetural.
* **Arquitetura:** Transformação do projeto de monolitíco para desacoplado com monolito de API.
* **Melhoria de Práticas:** Implementação de fluxos de CI/CD e *Design Patterns*.
* **Qualidade de Código:** Refatoração com foco em legibilidade, manutenibilidade e testes automatizados.
